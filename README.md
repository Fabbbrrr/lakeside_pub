# Le Mans Lakeside - track & build showcase

Marketing/showcase page for the Le Mans Lakeside kart circuit recreation for
Assetto Corsa (Dandenong South, VIC).

Generated by `scripts/10_build_pub_site.py` in the private `lemans` repo and
published with `scripts/publish_pub_site.sh`. Images are offline renders of the
public (CC0) build - no satellite imagery, no third-party photos.

Live: https://fabbbrrr.github.io/lakeside_pub/

Map data (c) OpenStreetMap contributors (ODbL). Textures from Poly Haven (CC0).
kn5 exporter by Thomas Hagnhofer & Paul Greveson (GPL-3.0).
